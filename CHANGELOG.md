# Changelog

This package uses Changesets for release notes.

## 1.0.0 - 2026-07-28

### Features

- Add progressively enhanced single- and multiple-answer quiz forms with practice, exam,
  and review modes.
- Add exact, partial, and all-or-nothing scoring, configurable attempts, answer reveal,
  reset, progress, and optional answer shuffling.
- Add a typed, localizable message catalog with safe English fallbacks.
- Add typed lifecycle events and subscription helpers for initialization, changes, checks,
  results, retries, reveals, resets, refreshes, completion, and teardown.
- Add dynamic-content refresh with optional selection preservation and predictable focus
  recovery.
- Add default accessible styles, package documentation metadata, and six interactive
  examples.

### Accessibility and lifecycle

- Preserve native form semantics, author-provided descriptions, and initial control state.
- Associate validation, status, explanation, and answer-state feedback programmatically.
- Restore author-owned DOM state and answer order when an instance is destroyed.
- Include visible focus indicators, forced-colors support, reduced-motion handling, and
  responsive examples.
